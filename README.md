# Quera Python Solutions

## introduction
This project is my python codes for 5 questions from (quera.org) website in the Terminal.
the main goal of this project is to solve algorithmic problems in python without need for install any extra library in cmd.
in this folder we have 5 main files: Strict diet.py, Freedom of Speech Day in Barareh.py, Pythagorean triples.py, Diamond print.py and Star diamonds.py.

---

## 1. Strict diet
* **question link** : [Strict diet on Quera](https://quera.org/problemset/20256)

**question summary :**
in this question From Quera, Lite wants to lose weight for Fite so he checks the 5 letters health label on foods before buying them. the health label has 5 letters for sugar, fat, salt, trans fat and protein that can be red (R), yellow (Y) or green (G). a food is dangerous and he must not eat it if it has at least 3 red letters, or at least 2 red and 2 yellow letters, or if all letters are red or yellow (no green at all). if it is dangerous the program must print (nakhor lite) and if it is safe it prints (rahat baash).

---

## 2. Freedom of Speech Day in Barareh
* **question link** : [Freedom of Speech Day in Barareh on Quera](https://quera.org/problemset/10162)

**question summary :**
today is freedom of speech day in Barareh and people from (Bala Barare) and (Payin Barare) take turns to say bad words to each other in the town square. in step 1 one person from Bala Barare talks to Payin Barare, in step 2 two people from Payin Barare talk back, in step 3 three people from Bala Barare talk, and it goes on like this until one side says (K) bad words in one turn. at that time the other side gets angry first and a fight starts. we get (K) from 1 to 100 in input and we must print which side gets angry first: (Bala Barare) or (Payin Barare).

## 3. Pythagorean triples
* **question link** : [Pythagorean triples on Quera](https://quera.org/problemset/280)

**question summary :**
in this question we must get 3 positive numbers (a, b, c) between 1 and 150 in three lines from the user. then the program checks if we can make a right triangle (ghaem ol zavieh) with these 3 side lengths or not. if we can make a right triangle with them it prints (YES) in output and if not it prints (NO).

---

## 4. Diamond print
* **question link** : [Diamond print on Quera](https://quera.org/problemset/618)

**question summary :**
in this problem the program gets a positive number (n) between 1 and 10 from the user in one line. then we must print a solid star diamond in the output that has a diameter size of (2*n+1).

## 5. Star diamonds
* **question link** : [Star diamonds on Quera](https://quera.org/problemset/9773)

**question summary :**
in this question we get an odd number (n) in the input, and the program must print two solid star diamonds with diameter size (n) right next to each other on the same lines in the output.
